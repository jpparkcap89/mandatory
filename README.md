# Zero-ON 법정의무연수 이수 관리

교원 법정의무연수 이수 여부를 **선생님이 직접 표시**하고, **담당자가 학교 전체 현황을 대시보드로 확인**하는 웹앱입니다.

- 프론트엔드: GitHub Pages (이 저장소의 `index.html`, `assets/`)
- 백엔드: Google Apps Script 웹 앱 (`gas/Code.gs`)
- DB: Google 스프레드시트 (설정 · 교원명단 · 연수목록 · 이수기록 · 추가요청 · 변경기록 시트)

`assets/config.js`의 `API_URL`이 비어 있으면 데모 모드(데이터는 그 브라우저에만 저장, 담당자 비밀번호 `demo1234`)로 열립니다.

## 기능

| 누가 | 할 수 있는 일 |
|---|---|
| 선생님 | 이름과 비밀번호로 로그인합니다. 처음 비밀번호는 `1234`이고, 첫 로그인 때 본인 비밀번호로 바꿉니다. 명단에 없는 이름이면 그 자리에서 담당자에게 추가를 요청합니다. 대시보드에서 이수율 고리, 완료·남은 연수, 다음에 들을 연수(수강 링크)를 봅니다. 체크리스트에서 이수 여부·이수일·이수번호를 기록합니다. |
| 담당자 | 비밀번호로 로그인합니다. 교원 명단을 엑셀(.xlsx·.xls)이나 CSV(UTF-8·EUC-KR)로 올리고, 반영 전에 신규·변경·건너뜀을 미리 봅니다. 추가 요청을 승인하거나 거절합니다. 연수별 이수율과 미이수 교원 명단(이름 복사)을 확인합니다. 교원별 이수 현황을 보고, 교원을 집계에서 제외·포함하고 비밀번호를 초기화합니다. 연수 항목을 숨기거나 다시 쓰고, 전체 현황을 엑셀로 내려받습니다. |

연수 목록은 2026 경기(평택) 교원 법정의무연수 25개 항목이 기본으로 들어 있습니다(학교폭력 예방교육은 1·2학기로 나눔). `setup`을 실행하면 `연수목록` 시트에 채워지고, 이름·주기·링크는 그 시트에서 고칩니다.

## 설치 (처음 한 번, 약 10분)

### 1. 스프레드시트와 Apps Script

1. Google 드라이브에서 새 스프레드시트를 만듭니다. 이름은 예를 들어 `법정의무연수 이수 DB`로 합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 `gas/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 왼쪽 ⚙️ **프로젝트 설정**에서 "편집기에 appsscript.json 매니페스트 파일 표시"를 켭니다. 그다음 `appsscript.json`을 이 저장소의 `gas/appsscript.json`으로 바꿉니다. 시간대가 서울로 맞춰집니다.
5. 함수 목록에서 `setup`을 고르고 **실행**합니다. 처음 실행할 때 권한 승인을 요청합니다.
6. 실행 로그에 나온 **담당자 비밀번호**를 적어 둡니다. 바꾸려면 프로젝트 설정 → 스크립트 속성에서 `ADMIN_PASSWORD` 값을 고칩니다.

### 2. 웹 앱 배포

1. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형을 **웹 앱**으로 고릅니다.
2. 다음 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 정합니다.
3. 배포하면 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 화면 파일을 고치면 `index.html`의 `?v=` 값을 함께 올려 주세요. 브라우저가 예전 파일을 쓰지 않습니다.
> 코드를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로입니다.

### 3. 프론트엔드 연결

1. `assets/config.js`의 `API_URL`에 복사한 URL을 넣고 커밋합니다.
2. GitHub 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/`로 접속합니다. 담당자는 주소 끝에 `#admin`을 붙이면 바로 담당자 화면이 열립니다.

## 운영 안내

- **명단 업로드**: 머리글에 `이름`(또는 `성명`) 열이 꼭 있어야 하고, `신분`·`부서`·`교사ID` 열은 있으면 함께 반영합니다. 기존 Zero-ON 엑셀 파일(`교사별현황` 시트)을 그대로 올려도 인식합니다.
- **전출·휴직**: 교원을 지우지 않고 집계에서 제외합니다. 이수 기록은 남습니다. 업로드할 때 "파일에 없는 기존 교원은 집계 제외" 옵션을 켜면 한 번에 처리됩니다.
- **같은 이름**: 부서나 교사ID로 구분합니다. 로그인할 때는 선생님이 본인(부서 표시)을 고릅니다.
- **비밀번호 분실**: 담당자가 교원별 화면에서 초기화하면 `1234`로 돌아가고, 선생님이 1234로 로그인한 뒤 새로 정합니다. 비밀번호는 해시로만 저장됩니다. 5번 틀리면 10분 동안 잠깁니다.
- **새 학년도**: `설정` 시트의 `연도` 값을 바꾸면 그 연도의 기록으로 새로 집계합니다. 이전 연도 기록은 `이수기록` 시트에 남아 있습니다.
- 체크는 선생님 본인이 남기는 확인 기록입니다. 시간·실습·학기·다년 주기 조건의 충족 여부와 법적 이수 인정은 수료증과 학교 확인 절차를 따릅니다.
- 교직원 이름이 담긴 스프레드시트는 우리 학교 담당자에게만 공유하세요.

